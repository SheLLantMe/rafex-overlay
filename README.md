# Rafex Overlay — трафарет поверх любых программ

## Запуск (нужен Node.js: https://nodejs.org)
    npm install
    npm start

## Сборка в .exe (portable, без установки)
    npm run build
Готовый файл появится в папке dist/.

## Как пользоваться
1. Вставь ссылку или выбери файл → «Загрузить».
2. В режиме «РЕДАКТИРУЮ» перетащи трафарет на нужное место, подбери размер/прозрачность/поворот, сотри лишнее ластиком.
3. Нажми F8 → «РИСУЮ»: окно становится сквозным, клики идут в программу под трафаретом (Roblox, Paint, Photoshop и т.д.).
4. Нужно подвинуть — снова F8.

Горячие клавиши: F8 — режим, F9 — спрятать/показать, F10 — выход.

## Важно
- Игра должна быть в оконном режиме или «окно без рамки» (borderless). Поверх эксклюзивного полноэкранного режима оверлей не отображается.
- Программа показывается на основном мониторе.
